# ก.พ. Trainer (PWA)

แอปฝึกข้อสอบ ก.พ. ภาค ก สำหรับมือถือ เน้น 2 วิชา
- 🇬🇧 **ภาษาอังกฤษ** (เกณฑ์ผ่าน 50%): Conversation, Vocabulary, Grammar, Reading
- ⚖️ **ความรู้และลักษณะการเป็นข้าราชการที่ดี** (เกณฑ์ผ่าน 60%): ทุกข้ออ้างอิงมาตราจริง

แยกจากแอป TOEIC โดยสิ้นเชิง ทั้งโค้ด ข้อมูลในเครื่อง ไฟล์สำรอง และ sync

## ฟีเจอร์

| เมนู | ทำอะไร |
|---|---|
| 🏠 หน้าแรก | ชุดประจำวัน 10 ข้อ (อังกฤษ 5 + ข้าราชการที่ดี 5) และแถบความพร้อมเทียบเกณฑ์ผ่านรายวิชา |
| 📝 ฝึก | สุ่มตามวิชา · ข้อที่ยังไม่เคยทำ · ข้อที่เคยผิด · เลือกตามหัวข้อกฎหมาย |
| ⏱️ จำลองสอบ | 50 ข้อ (25+25) จับเวลา ไม่เฉลยระหว่างทำ ตัดสินผ่าน/ไม่ผ่านรายวิชา ปิดแอปกลางคันแล้วกลับมาทำต่อได้ |
| 🃏 การ์ด | การ์ดกฎหมาย (ตัวเลขวัน มาตรา) และคำศัพท์อังกฤษ ทบทวนแบบ spaced repetition + เกมคำศัพท์ |
| 📊 สถิติ | streak, ความแม่นยำรายวิชา/รายหัวข้อ, ประวัติจำลองสอบ |

**ชุดประจำวันฉลาดขึ้นทุกวัน:** ข้อที่เคยตอบผิดจะกลับมาก่อน ตามด้วยข้อที่ยังไม่เคยทำ

## เนื้อหาตั้งต้น

- ข้าราชการที่ดี 50 ข้อ จาก 6 กฎหมาย: พ.ร.บ.ระเบียบบริหารราชการแผ่นดิน · พ.ร.ฎ.บริหารกิจการบ้านเมืองที่ดี ·
  พ.ร.บ.วิธีปฏิบัติราชการทางปกครอง · พ.ร.บ.ความรับผิดทางละเมิดของเจ้าหน้าที่ · พ.ร.บ.มาตรฐานทางจริยธรรม · ป.อาญา ม.147–157
- ภาษาอังกฤษ 34 ข้อ · การ์ดกฎหมาย 36 ใบ · คำศัพท์ 40 คำ

ข้อสอบเขียนขึ้นใหม่ตามรูปแบบข้อสอบจริง (ไม่ได้คัดลอกข้อสอบเก่าหรือหนังสือติว) ข้อกฎหมายเขียนจากตัวบท
และระบุมาตราไว้ทุกข้อ ควรตรวจกับตัวบทล่าสุดที่ krisdika.go.th อีกครั้ง เพราะกฎหมายอาจมีการแก้ไข

## ขึ้นเว็บด้วย GitHub Pages (ใช้บัญชีเดียวกับ TOEIC ได้)

1. GitHub → **+** → **New repository** → ชื่อ `kp-trainer` → **Public** → Create
2. กด **uploading an existing file**
3. เปิดโฟลเดอร์ `kp-pwa` กด **Ctrl+A** แล้ว **ลากไปวาง** (ห้ามใช้ปุ่ม choose your files เพราะเลือกโฟลเดอร์ไม่ได้)
4. **ตรวจก่อน Commit:** ต้องเห็น `js/app.js`, `js/config.js`, `data/questions.json` (มี `js/` และ `data/` นำหน้า)
5. **Commit changes** → **Settings** → **Pages** → Branch: **main** / **(root)** → Save
6. รอ 1–2 นาที ลิงก์คือ `https://ชื่อผู้ใช้.github.io/kp-trainer/`

> แอป TOEIC กับแอปนี้อยู่ใต้โดเมนเดียวกัน (`ชื่อผู้ใช้.github.io`) เบราว์เซอร์จึงให้ใช้พื้นที่เก็บข้อมูลร่วมกัน
> ทุกชื่อที่ใช้เก็บข้อมูลจึงตั้งไว้ไม่ให้ซ้ำกันใน `js/config.js` และ `sw.js` (prefix `kp`) **ห้ามแก้ให้ซ้ำกับของ TOEIC**

## ติดตั้งบน iPhone / แชร์ให้คนอื่น

- iPhone: เปิดด้วย Safari → Share → **Add to Home Screen** แล้วใช้จากไอคอนเท่านั้น
- ในแอป: ⚙️ → **แชร์ลิงก์แอป** → ส่งเข้า LINE (ลิงก์จะเปิดใน Safari/Chrome ให้อัตโนมัติ)
- คนที่เปิดครั้งแรกจะเจอหน้าแนะนำและวิธีติดตั้งที่ตรงกับมือถือของเขา

## Sync หลายเครื่อง (ไม่บังคับ)

⚙️ → ขั้นสูง → วาง GitHub token ที่มีสิทธิ์ `gist` **ใช้ token เดียวกับแอป TOEIC ได้**
แต่ละแอปเก็บไฟล์แยกกันใน Gist และแอปนี้ไม่ยอมรับไฟล์สำรองของแอป TOEIC

## ข้อสอบจากไฟล์ส่วนตัว (เช่น PDF ข้อสอบจริง)

Import ผ่าน ⚙️ → **กู้คืนจากไฟล์สำรอง** บนมือถือของตัวเองเท่านั้น ข้อสอบจะอยู่ในเครื่องนั้น (และไฟล์สำรอง/Gist ของคุณ)
**ห้ามใส่ลงในโฟลเดอร์ `data/`** เพราะ repo เป็น public ทุกคนจะดาวน์โหลดได้

แอปรองรับ: ตัวเลือก 4 หรือ 5 ข้อ (ก–จ), บทความที่ใช้ร่วมหลายข้อ, ช่อง `"origin": "real"` เพื่อให้ขึ้นในปุ่ม
"ข้อสอบจริงปีย้อนหลัง", และหัวข้อ `other_law` (กฎหมายอื่น ๆ)

## เพิ่มข้อสอบ

ดู `prompts/generate_content.md` (แนบตัวบทกฎหมายไปกับ prompt ด้วยทุกครั้ง)

## อัปเดตแอป

อัปโหลดไฟล์ที่เปลี่ยน แล้ว **แก้ `VERSION` ใน `sw.js`** (เช่น `v1` → `v2`) ทุกครั้ง

## โครงสร้าง

```
js/config.js   ชื่อแอป namespace วิชา เกณฑ์ผ่าน หัวข้อ  ← จุดที่ต้องแก้ถ้าจะปรับแอป
js/app.js      หน้าจอทั้งหมด
js/store.js    event log ใน IndexedDB + คำนวณสถานะ/สถิติ
js/srs.js      อัลกอริทึม SM-2
js/sync.js     sync ผ่าน Gist + สำรองไฟล์
data/          questions.json, cards.json
```

ทดสอบบนคอมพิวเตอร์: `python -m http.server 8000` ในโฟลเดอร์นี้ แล้วเปิด http://localhost:8000
